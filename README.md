# LMS (Learning Management System)

## Описание проекта

В мире развивается тренд на онлайн-обучение. Веб-разработчики должны не только обучаться, но и уметь создавать платформы для онлайн-обучения. Этот проект представляет собой систему управления обучением (LMS), где каждый желающий может размещать свои полезные материалы или курсы.

Проект реализует бэкенд-сервер с использованием Django и Django REST Framework (DRF) для возврата JSON-структур клиенту.

Этот проект демонстрирует, как реализовать систему управления пользователями и ресурсами с использованием Django и Django REST Framework, а также настроить уровни доступа для различных типов пользователей. 

Проект включает в себя управление курсами и уроками, подписками на обновления курсов и интеграцию с платежной системой Stripe.

## Установка и настройка

### Предварительные требования

- Python 3.12 или выше
- Django 5.2 или выше
- Django REST Framework
- PostgreSQL
- Simple JWT
- Celery
- Redis

### Установка

1. Клонируйте репозиторий:
   git clone https://github.com/Vitaly-Shcheglov/Django-LMS-project.git

2. Установите зависимости:
   pip install -r requirements.txt


3. Создайте базу данных в PostgreSQL и настройте подключение в `settings.py`

4. Создайте новые миграции и примените их:
   python manage.py makemigrations
   python manage.py migrate

4. Создайте суперпользователя (по желанию):
   python manage.py createsuperuser

5. Запустите сервер:
   python manage.py runserver.

6. Установите и настройте Redis:
- **Для Windows**: Используйте WSL или [Redis для Windows](https://github.com/microsoftarchive/redis/releases).
- **Для Linux**: Установите Redis с помощью пакетного менеджера:

sudo apt-get update
sudo apt-get install redis-server

- **Для macOS**: Установите Redis с помощью Homebrew:
brew install redis

Запустите Redis сервер:
redis-server

7. Настройка API ключей Stripe
Зарегистрируйтесь на [Stripe Dashboard](https://dashboard.stripe.com/register) и получите тестовые API ключи. Сохраните ключи в `settings.py` проекта.

8. Настройка переменных окружения
Создайте файл `.env` на сервере и добавьте все необходимые переменные окружения. Пример шаблона `.env`:

DEBUG=False
SECRETKEY=вашсекретныйключ
DATABASEURL=вашURLбазыданных

9. Запуск миграций
python manage.py migrate

10. Запуск сервера
python manage.py runserver 0.0.0.0:8000

11. Запуск Workflow
После внесения изменений в код, просто выполните push в репозиторий, и GitHub Actions автоматически запустит тесты и деплой.


## Проверка работы API

Используйте Postman для тестирования следующих эндпоинтов:

- **GET** `/api/users/profile/` - Получить профиль текущего пользователя
- **GET** `/api/courses/` - Получить список курсов.
- **POST** `/api/courses/` - Создать новый курс.
- **GET** `/api/lessons/` - Получить список уроков.
- **POST** `/api/lessons/` - Создать новый урок.
- **GET** `/api/users/payments/` - Получить список платежей с возможностью фильтрации.
- **POST** `/api/register/` - Регистрация.
- **POST** `/api/token/` - Авторизация
- **GET** `/api/users/` - Просмотр пользователей.
- **POST** `/api/users/` - Создание пользователя.
- **PUT** `/api/users/{id}/` - Обновление пользователя.
- **DELETE** `/api/users/{id}/` - Удаление пользователя/


## Подробнее

Чтобы проверить работу ваших эндпоинтов с помощью Postman, вам нужно выполнить следующие шаги:

### 1. Проверка CRUD для курсов

#### GET - Получение списка курсов

- URL: http://127.0.0.1:8000/api/courses/
- Метод: GET
- Описание: Этот запрос вернет список всех курсов.

#### POST - Создание нового курса

- URL: http://127.0.0.1:8000/api/courses/
- Метод: POST
- Тело запроса (JSON):

   {
       "title": "Название курса",
       "preview": "URL_картинки_превью",
       "description": "Описание курса"
   }

#### PUT - Обновление существующего курса

- URL: http://127.0.0.1:8000/api/courses/{id}/
- Метод: PUT
- Описание: Замените {id} на ID курса, который вы хотите обновить.
- Тело запроса (JSON):

   {
       "title": "Новое название курса",
       "preview": "Новый_URL_картинки_превью",
       "description": "Новое описание курса"
   }

#### DELETE - Удаление курса

- URL: http://127.0.0.1:8000/api/courses/{id}/
- Метод: DELETE
- Описание: Замените {id} на ID курса, который вы хотите удалить.

### 2. Проверка CRUD для уроков

#### GET - Получение списка всех уроков

- URL: http://127.0.0.1:8000/api/lessons/
- Метод: GET
- Заголовки (Headers): Authorization: Bearer ваш_токен_здесь
- Описание: Этот запрос вернет список всех уроков.

#### POST - Создание нового урока

- URL: http://127.0.0.1:8000/api/lessons/
- Метод: POST
- Заголовки (Headers): Authorization: Bearer ваш_токен_здесь
- Тело запроса (JSON):

   {
       "title": "Название урока",
       "description": "Описание урока",
       "preview": "URL_картинки_превью",
       "video_link": "URL_видео"
   }

#### PUT - Обновление существующего урока

- URL: http://127.0.0.1:8000/api/lessons/{id}/
- Метод: PUT
- Описание: Замените {id} на ID урока, который вы хотите обновить.
- Заголовки (Headers): Authorization: Bearer ваш_токен_здесь
- Тело запроса (JSON):

   {
       "title": "Новое название урока",
       "description": "Новое описание урока",
       "preview": "Новый_URL_картинки_превью",
       "video_link": "Новый_URL_видео"
   }

#### DELETE - Удаление урока:

- URL: http://127.0.0.1:8000/api/lessons/{id}/
- Метод: DELETE
- Заголовки (Headers): Authorization: Bearer ваш_токен_здесь.
- Описание: Замените {id} на ID урока, который вы хотите удалить.

#### Получение списка уроков с фильтрацией:
   - Метод: GET
   - URL: http://127.0.0.1:8000/api/lessons/?course=1 (где 1 — это ID курса, по которому вы хотите фильтровать)

#### Сортировка уроков:
   - Вы можете добавить параметр ordering в URL: http://127.0.0.1:8000/api/lessons/?ordering=title.

#### Получение доступа к уроку:

- URL: http://localhost:8000/api/lessons/{id}/
- Метод: GET
- Заголовки (Headers): Authorization: Bearer ваш_токен_здесь

### Использование Postman

1. Откройте Postman.
2. Создайте новый запрос:
   - Нажмите на "New" и выберите "Request".
   - Введите имя запроса и выберите коллекцию для сохранения (или создайте новую).
3. Выберите метод (GET, POST, PUT, DELETE) и введите URL.
4. Добавьте тело запроса:
   - Для POST и PUT выберите "Body" и установите тип на "raw" с форматом JSON.
   - Вставьте JSON-данные в текстовое поле.
5. Нажмите "Send" для выполнения запроса и посмотрите на ответ
