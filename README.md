# LMS (Learning Management System)

## Описание проекта

В мире развивается тренд на онлайн-обучение. Веб-разработчики должны не только обучаться, но и уметь создавать платформы для онлайн-обучения. Этот проект представляет собой систему управления обучением (LMS), где каждый желающий может размещать свои полезные материалы или курсы.

Проект реализует бэкенд-сервер с использованием Django и Django REST Framework (DRF) для возврата JSON-структур клиенту.

## Задания

### Задание 1: Создание нового Django-проекта

1. Создайте новый Django-проект.
2. Подключите Django REST Framework в настройках проекта.

### Задание 2: Создание моделей

1. **Пользователь**:
   - Все поля от обычного пользователя, но авторизация заменена на email.
   - Телефон.
   - Город.
   - Аватарка.
   - Модель пользователя размещена в приложении `users`.

2. **Курс**:
   - Название.
   - Превью (картинка).
   - Описание.

3. **Урок**:
   - Название.
   - Описание.
   - Превью (картинка).
   - Ссылка на видео.
   - Урок и курс связаны между собой. Уроки складываются в курс, и в одном курсе может быть много уроков.
   - Модели курса и урока размещены в отдельном приложении (например, `lms` или `materials`).

### Задание 3: Описание CRUD

1. Опишите CRUD для моделей курса и урока.
   - Для реализации CRUD для курса используйте Viewsets.
   - Для урока используйте Generic-классы.
   - Опишите простейшие сериализаторы для работы контроллеров.
   - Реализуйте все необходимые операции для уроков (получение списка, получение одной сущности, создание, изменение и удаление).
   - Проверьте работу каждого эндпоинта с помощью Postman.

### Дополнительное задание

Реализуйте эндпоинт для редактирования профиля любого пользователя, используя более привлекательный подход (Viewset или Generic).

## Установка и настройка

### Предварительные требования

- Python 3.12 или выше
- Django 5.2 или выше
- Django REST Framework

### Установка

1. Клонируйте репозиторий:
   git clone https://github.com/Vitaly-Shcheglov/Django-LMS-system-project.git

2. Установите зависимости:
   pip install -r requirements.txt

3. Создайте файл миграций и примените их:
   python manage.py makemigrations
   python manage.py migrate

4. Создайте суперпользователя (по желанию):
   python manage.py createsuperuser

5. Запустите сервер:
   python manage.py runserver


## Проверка работы API

Используйте Postman для тестирования следующих эндпоинтов:

- **GET** `/api/users/profile/` - Получить профиль текущего пользователя.
- **GET** `/api/courses/` - Получить список курсов.
- **POST** `/api/courses/` - Создать новый курс.
- **GET** `/api/lessons/` - Получить список уроков.
- **POST** `/api/lessons/` - Создать новый урок.

## Подробнее

Чтобы проверить работу ваших эндпоинтов с помощью Postman, вам нужно выполнить следующие шаги:

### 1. Проверка CRUD для курсов

#### GET - Получение списка курсов

- URL: http://127.0.0.1:8000/api/courses/
- Метод: GET
- Описание: Этот запрос вернет список всех курсов.

#### POST - Создание нового курса

- URL: http://127.0.0.1:8000/api/courses/
- Метод: POST
- Тело запроса (JSON):

   {
       "title": "Название курса",
       "preview": "URL_картинки_превью",
       "description": "Описание курса"
   }


#### PUT - Обновление существующего курса

- URL: http://127.0.0.1:8000/api/courses/{id}/
- Метод: PUT
- Описание: Замените {id} на ID курса, который вы хотите обновить.
- Тело запроса (JSON):

   {
       "title": "Новое название курса",
       "preview": "Новый_URL_картинки_превью",
       "description": "Новое описание курса"
   }


#### DELETE - Удаление курса

- URL: http://127.0.0.1:8000/api/courses/{id}/
- Метод: DELETE
- Описание: Замените {id} на ID курса, который вы хотите удалить.

### 3. Редактирование профиля пользователя

#### PUT - Обновление профиля пользователя

- URL: http://127.0.0.1:8000/api/users/profile/
- Метод: PUT
- Тело запроса (JSON):

   {
       "phone": "Номер телефона",
       "city": "Город",
       "avatar": "URL аватарки"  // Если вы хотите изменить аватарку
   }


### Использование Postman

1. Откройте Postman.
2. Создайте новый запрос:
   - Нажмите на "New" и выберите "Request".
   - Введите имя запроса и выберите коллекцию для сохранения (или создайте новую).
3. Выберите метод (GET, POST, PUT, DELETE) и введите URL.
4. Добавьте тело запроса:
   - Для POST и PUT выберите "Body" и установите тип на "raw" с форматом JSON.
   - Вставьте JSON-данные в текстовое поле.
5. Нажмите "Send" для выполнения запроса и посмотрите на ответ.
